# 🎨 Protótipo de Alta Fidelidade – UX Design  
Simulação prática do processo de criação de interfaces profissionais usando Figma

Este projeto consiste no desenvolvimento de um **protótipo de alta fidelidade**, criado para fins educacionais dentro da disciplina de **Experiência do Usuário (UX)**.  
O trabalho aplica conceitos de **UI, UX, fluxos de navegação, tipografia, cores e acessibilidade**, seguindo os conteúdos das Aulas **01 a 06**.

---

## 🚀 Começando
Estas instruções ajudam a acessar, visualizar e navegar pelo protótipo no Figma.

---

## 📋 Pré-requisitos
Para editar ou visualizar o protótipo, você precisa de:

- Navegador atualizado (Chrome, Edge, Firefox...)  
- Conta no **Figma** (gratuita)

Acesse:  
https://www.figma.com

## 🔧 Acesso ao Projeto

1️⃣ **Acesse o link do protótipo**  
*(insira aqui o link do Figma quando disponível)*

2️⃣ Abra no **Figma** (modo editor) ou clique em **Play ▶ Prototype** para testar a navegação.

3️⃣ Navegue pelas telas conforme o fluxo proposto (exemplo):  
**Login → Home → Explorar → Detalhes → Perfil/Configurações**

## 🎨 Estrutura do Projeto

O protótipo foi desenvolvido com foco em:

- Organização de frames  
- Biblioteca visual  
- Componentes reutilizáveis  
- Fluxo interativo entre as páginas  
- Responsividade conceitual (opcional)

---

## 📚 Funcionalidades do Protótipo

- Layouts desenhados em alta fidelidade  
- Paleta de cores definida conforme Aula 05  
- Hierarquia tipográfica completa  
- Ícones, botões e componentes estilizados  
- Navegação interativa completa  
- Acessibilidade aplicada (contraste, legibilidade, escala)  
- Fluxo mínimo de **5 telas** conectadas  
- Uso de boas práticas de UI/UX
